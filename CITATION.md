# Citation / 引用

If NFE MXene Studio, its dataset, or its trained models contribute to an
academic publication, please cite the software release and the associated
dataset. Machine-readable metadata is provided in [`CITATION.cff`](CITATION.cff).

如果 NFE MXene Studio、项目数据集或训练模型对学术成果作出贡献，请同时引用
软件版本和相关数据集。机器可读的引用信息见 [`CITATION.cff`](CITATION.cff)。

## Software citation / 软件引用

Before a permanent DOI is assigned, use:

```bibtex
@software{ruck_nfe_mxene_studio_2026,
  author  = {Ruck},
  title   = {NFE MXene Studio},
  version = {1.0},
  year    = {2026},
  url     = {https://github.com/lutengluo/Ruck-NFE-MXene-Studio}
}
```

取得 Zenodo DOI 后，应以 DOI 记录替换上述临时 GitHub 引用，并在本文件与
`CITATION.cff` 中同步更新。

## Attribution and citation / 署名与引用

License attribution and scholarly citation are related but distinct:

- retain the copyright, license, and NOTICE files when redistributing;
- identify modified versions and describe substantial changes;
- cite the software and dataset in publications, reports, and derived research;
- do not imply endorsement by the author.

许可证署名义务与学术引用并不完全相同。再分发时必须保留版权、许可证和 NOTICE
文件并标记修改；发表论文、报告或衍生研究时，请规范引用软件和数据集。
